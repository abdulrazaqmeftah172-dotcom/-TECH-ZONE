TECH ZONE - متجر إلكترونيات تجريبي
====================================

التشغيل:
1) فك ضغط الملف.
2) افتح مجلد tech_zone_store.
3) افتح index.html بمتصفح Chrome أو Edge.
   لا يحتاج إلى تثبيت برامج أو خادم محلي للنسخة التجريبية.

الملفات:
- index.html : هيكل صفحات المتجر.
- style.css  : التصميم والألوان والتجاوب مع الجوال.
- script.js  : المنتجات والبحث والفلاتر والسلة والطلبات التجريبية.

تعديل المتجر قبل تسليمه للعميل:
1) غيّر TECH ZONE وبيانات التواصل والعنوان داخل index.html.
2) غيّر بيانات المنتجات والأسعار والأقسام داخل مصفوفة products في script.js.
3) غيّر العملة من الدالة money() في script.js.
4) روابط صور المنتجات حالياً صور خارجية من Unsplash؛ يلزم اتصال إنترنت لعرضها.
   لاستضافة صور محلية: أنشئ مجلد images وضع الصور داخله، ثم استبدل روابط image بمسارات مثل images/phone.jpg.
5) حدّث روابط التواصل الاجتماعي في أسفل index.html.

تنبيه مهم قبل الإطلاق التجاري:
هذه واجهة Front-End تجريبية. السلة والطلبات تحفظ باستخدام LocalStorage في المتصفح نفسه فقط.
لا يوجد حالياً خادم أو قاعدة بيانات مشتركة أو حسابات عملاء حقيقية أو بوابة دفع إلكتروني.
لا تعتمد عليها لاستقبال طلبات فعلية من العملاء قبل ربط Backend آمن، قاعدة بيانات،
لوحة إدارة حقيقية، واتساب/بريد لاستلام الطلبات، وبوابة دفع مناسبة لبلد النشاط.
لا تضع مفاتيح سرية أو بيانات دفع في ملفات JavaScript العامة.

ملاحظة:
الأسعار والمنتجات والعملات افتراضية لأغراض العرض، ويجب مراجعتها مع صاحب المتجر.
